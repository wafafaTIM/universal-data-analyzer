# Universal Data Analyzer

## Project Description
Universal Data Analyzer is a Python-based project that reads, cleans, analyzes, and visualizes sales data.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Project Features
- Load CSV data
- Display dataset information
- Detect and remove duplicate records
- Handle missing and invalid values
- Clean text and date columns
- Convert numeric columns
- Calculate revenue
- Analyze sales by category, region, and product
- Identify highest and lowest orders
- Generate sales charts
- Export cleaned data to CSV

## Project Structure

universal-data-analyzer/
- data/
- output/
- main.py
- requirements.txt
- README.md

## How to Run

1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the project:

   python main.py
